# My First Data Science Project

Pierwszy projekt Data Science utworzony podczas kursu
Data Scientist Online + AI w LearnIT.

## Cel projektu

Nauka podstaw systemu kontroli wersji Git, w tym:
- inicjalizacji lokalnego repozytorium,
- śledzenia zmian w plikach,
- dodawania plików do staging area,
- tworzenia commitów,
- przeglądania historii zmian.
