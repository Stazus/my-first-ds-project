# My First Data Science Project

Pierwszy projekt Data Science utworzony podczas kursu
Data Scientist Online + AI w LearnIT.

## Cel projektu

Nauka podstaw systemu kontroli wersji Git, w tym:
- inicjalizacji lokalnego repozytorium,
- śledzenia zmian w plikach,
- dodawania plików do staging area,
- tworzenia commitów,
- przeglądania historii zmian.

## Technologie

- Git
- Python
- GitHub

Projekt wykorzystuje Git do śledzenia zmian
i zarządzania historią kodu.

## Synchronizacja z GitHub

Zadanie 7 - Test synchronizacji repozytorium
lokalnego ze zdalnym za pomocą git push i git pull.

## Porównywanie zmian - git diff

Zadanie 8 - Nauka porównywania zmian między wersjami plików.

Git diff pozwala sprawdzić zmiany przed utworzeniem commita.
Git diff HEAD~1 HEAD umożliwia porównanie dwóch ostatnich commitów.
Można również porównywać dowolne commity za pomocą ich identyfikatorów.
